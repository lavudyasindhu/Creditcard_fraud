What do these terms mean?

Threshold
The probability value used to decide whether a transaction is fraud.
Recall
Measures how many actual fraudulent transactions were correctly detected. Recall = TP / (TP + FN).
Confusion matrix
Shows correct and incorrect predictions using TP, TN, FP and FN.
Trade-off
A lower threshold catches more fraud (higher recall) but raises false alarms (lower precision). A higher threshold does the opposite. Banks pick the balance that suits them.
